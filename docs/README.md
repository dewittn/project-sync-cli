# prjsync Documentation

Welcome to the prjsync documentation! This documentation is organized following the [Diátaxis framework](https://diataxis.fr/) to help you find the information you need quickly and efficiently.

## Documentation Structure

The documentation is divided into four categories, each serving a different purpose:

### Tutorials (Learning-Oriented)

Tutorials are lessons that take you by the hand through a series of steps to complete a project or learn a skill. Start here if you're new to prjsync.

- [Getting Started](tutorials/getting-started.md) - Requirements, installation, configuration, and your first sync
- [Field Mapping Walkthrough](tutorials/field-mapping.md) - Interactive guide to setting up field mappings

### How-To Guides (Task-Oriented)

How-to guides are recipes that guide you through the steps involved in addressing key problems and use-cases. Use these when you have a specific goal in mind.

- [Sync Projects](how-to/sync-projects.md) - Different sync scenarios with various flags and options
- [Status Tag Sync](how-to/status-sync.md) - Setting up and using bidirectional status synchronization
- [Troubleshooting](how-to/troubleshooting.md) - Common issues and their solutions

### Reference (Information-Oriented)

Reference guides contain technical descriptions of the machinery and how to operate it. Consult these when you need precise, detailed information.

- [Commands Reference](reference/commands.md) - Complete reference for all CLI commands and flags
- [Configuration](reference/configuration.md) - Detailed configuration file structure and options
- [Interactive Prompts](reference/interactive-prompts.md) - All interactive prompts explained
- [Operation Modes](reference/modes.md) - Verbose, Debug, Verification, and Dry-run modes

### Explanation (Understanding-Oriented)

Explanations clarify and illuminate a particular topic. They broaden the reader's understanding and provide context.

- [Architecture](explanation/architecture.md) - System design and how components work together
- [Project Structure](explanation/project-structure.md) - Codebase organization and file layout
- [Sync Strategy](explanation/sync-strategy.md) - Design decisions and sync logic deep dive

### Development

- [Development Guide](development.md) - Development setup, testing, code quality, and contributing
